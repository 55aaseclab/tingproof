# 听校产品需求

[English](PRD.en.md)

用户导入一对音频与字幕，在可访问项目内播放、定位、校对、标记疑点并导出字幕。各设备在本地选取所需音频，服务端以项目为范围管理字幕与修订状态。原始音频、字幕和账号配置放在私有存储中。

## Praxis 供数接口

应用通过版本 1 的 `praxis-provider.mjs` 提供有来源依据的工作台卡片与数据源描述。读取使用宿主提供的已授权回调，供数模块不直接访问文件、凭据或网络。保留原生对象入口、真实版本或稳定内容摘要，明确区分空态、部分失败与不可用。个人卡片处理不修改共享业务记录。参见[供数合同](PRAXIS-PROVIDER.md)。

原生 `?space=&assignment=` 入口只读取一个获授权任务及其分段，保留原文、校正稿、时间和状态。录音在设备上会话内关联、不上传；失去权限时清空内容。任务读取不产生整项目读取或写入权限。
