# 听校产品需求

[English](PRD.en.md)

应用发行版本：0.1.7

需求文档修订：V1.1.12

用户导入一对音频与字幕，在可访问项目内播放、定位、校对、标记疑点并导出字幕。各设备在本地选取所需音频，服务端以项目为范围管理字幕与修订状态。原始音频、字幕和账号配置放在私有存储中。

## Praxis 供数接口

应用通过版本 1 的 `praxis-provider.mjs` 提供有来源依据的工作台卡片与数据源描述。读取使用宿主提供的已授权回调，供数模块不直接访问文件、凭据或网络。保留原生对象入口、真实版本或稳定内容摘要，明确区分空态、部分失败与不可用。个人卡片处理不修改共享业务记录。参见[供数合同](PRAXIS-PROVIDER.md)。

原生 `?space=&assignment=` 入口只读取一个获授权任务及其分段，保留原文、校正稿、时间和状态。录音在设备上会话内关联、不上传；失去权限时清空内容。任务读取不产生整项目读取或写入权限。

## V1.1.12 · 原生任务校正权限

原生任务页面和编译后的公开资源只要求应用入口权限；查询参数不授予任务数据或整项目权限，`get_assignment` 仍逐次校验当前调用者对具体任务的授权。整项目 API 与原生升级连接继续执行完整的 native-projects 门禁。

缺失 `permissions.submit` 时默认只读。只有当前受控 `get_assignment` 明确返回 `permissions.submit: true` 才启用原生校正字段与「保存校正」，每次提交仍由服务端重新验权。复用原生字幕行、时间轴和播放器，仅提交授权段编号、校正文字及明确暂存的状态，携带当前预期版本和本次意图唯一的幂等键。回读任务核对后才确认保存。版本冲突保留草稿，展示最新校正并要求明确选择后重试；结果未知时用原键和原请求重试。失权时清空私有内容，不以读取整项目、导出或服务端原始录音绕过边界。
